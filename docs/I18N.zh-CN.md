# 国际化维护说明

FTP Synchronization 使用 Java 21 标准 `ResourceBundle` 与 JavaFX FXML 资源引用实现国际化。

## 资源文件

资源位于 `src/main/resources/i18n/`：

- `messages.properties`：英文基础资源，也是默认回退资源。
- `messages_zh_CN.properties`：简体中文。
- `messages_ja.properties`：日语。
- `messages_ko.properties`：韩语。

四个文件必须使用 UTF-8，并保持完全相同的资源键。新增或修改界面文案时应同步更新全部文件。

## FXML 文案

FXML 静态文案使用 JavaFX 标准资源语法，例如：

```xml
<Button text="%button.saveSettings"/>
<TextField promptText="%prompt.ruleName"/>
```

带参数的文案由控制器调用 `I18n.text("resource.key", arguments)` 设置。不要在 FXML 中写死中文，也不要根据翻译后的显示文本判断业务逻辑。

## 动态消息和日志

应用内部日志使用 `LocalizedMessage.localized(key, arguments)` 保存稳定资源键；界面显示时按当前语言渲染，因此切换语言后历史日志也会更新。FTP 服务器响应和外部异常原文使用 `LocalizedMessage.raw(text)`，不会被翻译或改写。

## 验证

执行：

```powershell
.\mvnw.cmd clean verify
```

测试会检查四个资源文件键集合、FXML 资源引用、中文硬编码、显式英文 Locale、四语窗口加载和历史日志重新渲染。
